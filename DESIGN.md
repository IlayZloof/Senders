## Tokens
- **Radius:** soft (`12px` / `8px`)
- **Color:** deep navy `#071824`, teal `#1a5f6f` / `#2a9d8f`, parchment `#e8e4d9`, coral accent `#ff6b4a`
- **Type:** Frank Ruhl Libre (display) + Assistant (body)
- **Texture:** subtle CSS cartographic grid + dashed map inset
- **Motion:** quiet panel rise 80–160ms stagger

1. Shorter photo hero + overlapping map-first CTA band
2. Tide-chart side panel (rows of community stats)

4. Underline-active nav (cartographic calm)
